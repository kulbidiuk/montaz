## Разбор инбокса (inbox triage)

Сырой поток мыслей лежит в `_BRAIN/Инбокс/inbox.md` (туда пишет Telegram-бот).
Каждый блок — это `## ДАТА ВРЕМЯ · источник` + текст + `---`.

### Что делать при разборе

1. Прочитай ВСЕ новые (ещё не разобранные) блоки в `inbox.md`.
2. Для каждого блока определи тип мысли и отправь по адресу из таблицы ниже.
3. Разобранный блок ВЫРЕЖИ из `inbox.md` и перенеси в `_BRAIN/Инбокс/_processed.md`
   (чтобы было видно, что ничего не потерялось).
4. В конце выдай построчный отчёт: `[мысль] → [куда положил, точный путь]`.

Если новых блоков нет — ответь «инбокс пуст».

### Маршрутизация — куда уходит мысль

| Тип мысли | Куда | Как записать |
|---|---|---|
| Факт / метод / цифра / найденный сервис | `_BRAIN/Заметки/` | 1-я строка — теги `#источник #тема`, потом резюме 2–3 строки, потом содержание |
| Решение с аргументацией | `_BRAIN/Решения/ADR-NNN_слаг_дата.md` | 5–10 строк: контекст, что выбрал, почему, последствия |
| Новая идея проекта | карточка в `_BRAIN/PROJECTS.md` | Цель / Следующий шаг / Дата |
| Чёткая задача | в проект, к которому относится (в `PROJECTS.md`) | пункт задач у нужного проекта |
| Влияет на фокус / деньги / сроки | `_BRAIN/Приоритеты.md` | пересчитать порядок по формуле ниже |
| Мелочь / мусор / легко восстановимое | отбросить | не плодить дубли |

### Правила записи

- Планка для заметки низкая: лучше короткая заметка с тегами, чем потерянная мысль.
- Тема уже есть в заметках → дополни существующий файл, не плоди дубль.
- Пробел в мысли (непонятно, что имелось в виду) → задай мне вопрос, НЕ выдумывай.
- Пиши решительно, без запроса «можно ли сохранить» — сохраняй и одной строкой сообщай путь.
- Доступы / ключи / домены / цены — не в Заметки, а в отдельный файл `_BRAIN/STACK.md`.

### Как выбирать задачи на день (формула приоритизации)

Каждую задачу оцени 0–3 по осям и посчитай скор:

**Скор = Деньги×2 + Рычаг + Обязательство − Операционка**

- Деньги: как скоро это даст реальный доход или проверит платящий спрос?
- Рычаг: остаётся ли актив, который дальше работает без меня (система, кейс, контент)?
- Обязательство: есть данное слово, дедлайн, закрывающееся окно?
- Операционка (минус): сколько постоянной ручной работы тянет и не делегируется?

Тайбрейкеры:

1. Данное слово / дедлайн бьёт всё — репутация дороже скора.
2. Ближе к деньгам бьёт «интересно, но далеко».
3. Актив, который копится, бьёт разовую операционку.

Бакеты: 🟢 СЕЙЧАС (максимум 3 задачи в дневном фокусе) · 🔵 ФОН (копится малыми шагами) · ⏸ ЗАМОРОЗ (хорошее, но не сейчас) · ⚫ СТОП (не делаем, чтобы не висело в голове).

### Утренний дайджест

Раз в день утром: разбери инбокс + собери сводку дня в `_BRAIN/Дайджесты/ДАТА.md`:

- 🎯 Главный приоритет дня (одна задача).
- ✅ Что ещё сделать сегодня (2–3 задачи по скору).
- 💤 Что можно сделать, если останется время.
- 🆕 Что обновилось по контексту (из новых мыслей инбокса).

Если подключены почта и календарь — учитывай письма и события дня.
